## First principles

- Find the actual bottleneck. There is no single perfect architecture; combine specialized tools across the performance curve.
- Latency changes behavior. Once machines call machines, waiting time multiplies and speed becomes capability.
- Determinism moves complexity from runtime into planning, making performance predictable and systems easier to reason about.
- Ask the right question before optimizing the answer; a precise problem definition is leverage.
- Intent is a leadership tool: after listening, declare what will happen instead of repeatedly inviting reasons it cannot.
- Preserve the team needed to cross the technical milestone, even when the survival financing is unconventional and shared.
- Hire against a written people specification, including tolerable weaknesses; generic “well-rounded” talent is not the goal.
- Manufacture discontent against mission delay, while recognizing that relentless pressure can distort judgment and exhaust people.

## Decision heuristics

Which specialized systems should be composed? What milestone changes the financing reality? Have we listened enough to state intent? Which weakness is acceptable for the extraordinary strength we need?

4. Closing comment: state one intent, milestone, or experiment that resolves the bottleneck.

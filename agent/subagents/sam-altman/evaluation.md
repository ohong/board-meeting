# Sam Altman — persona evaluation

Evaluated: 2026-09-03
Prompt: `sam-altman-v1.0.0`

## Method and status

This is a **static prompt-inspection evaluation**, not a live-model run. Four identical decisions were traced through this prompt, a generic-adviser baseline, Marc Andreessen, and Daniel Ek. Board behavior was checked against explicit instructions. No provider call, stochastic output capture, blind rating, or human fidelity review was run; results below are expected differentiation, not observed runtime behavior.

# Torsten Reil — persona evaluation

Evaluated: 2026-09-03
Prompt: `torsten-reil-v1.0.0`

## Method and status

This is a **static prompt-inspection evaluation**, not a live-model run. The same four decisions were traced through this prompt, a generic-adviser baseline, Daniel Ek, and Jonathan Ross. Board behavior cases were inspected against explicit instructions. No provider call, stochastic transcript, or human blind-rating was run, so behavioral conclusions are design expectations rather than runtime evidence.

## Boardroom behavior checks

- **Independent position:** Pass on instruction design; requires a specific pre-consensus view.
- **Direct @mention:** Pass; directs an on-point response using the supplied complete context.
- **Interruption opportunity:** Pass; only a consequential false assumption or missing field constraint warrants interruption.
- **Persuasive counterargument:** Pass; requires “That field evidence changes my view…” and a revised action.
- **Closing comment:** Pass; one next action, field test, or unresolved risk.
- **Passing:** Pass; only after at least one contribution and when nothing additive remains.
- **Shared-room protocol:** Pass; human chair and visible WebMCP participants are explicit; side conversations prohibited.

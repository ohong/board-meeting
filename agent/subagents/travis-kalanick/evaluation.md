# Travis Kalanick — persona evaluation

Evaluated: 2026-09-03
Prompt: `travis-kalanick-v1.0.0`

## Method and status

This is a **static prompt-inspection evaluation**, not a live-model run. The same decisions were traced through this prompt, a generic-adviser baseline, Tony Xu, and Brad Jacobs. Board behavior was checked against the written contract. No provider call, output transcript, blind rating, or human likeness review was run, so these are expected distinctions rather than runtime observations.

## Boardroom behavior checks

- **Independent position:** Pass by design; mission, mechanics, capacity, and boundary distance precede consensus.
- **Direct @mention:** Pass; requires one hard mechanistic answer from supplied context.
- **Interruption opportunity:** Pass; reserved for hidden problem creation, lost leverage, or a false marketplace assumption.
- **Persuasive counterargument:** Pass; requires a named mechanism and an explicit changed recommendation.
- **Closing comment:** Pass; one gate, owner, playbook, or unresolved risk.
- **Passing:** Pass; only after speaking and only without additive insight.
- **Shared-room protocol:** Pass; human chair and visible WebMCP participants are explicit; side conversations prohibited.
